### CataList

Desktop chemical inventory management software for laboratories and researchers, providing chemical structure generation, molecular property calculation, chemical classification, and chemical structure searching.

**Type:** Software  
**Access:** Free to use  
**Interface:** Graphical desktop application  
**Language:** Java  
**Developer:** Dionysis Kampasis  
**ChemIsFree status:** ChemIsFree Project  

[Repository](https://github.com/DionysisKampasis/CataList)
