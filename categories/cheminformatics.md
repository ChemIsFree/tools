# Cheminformatics

Tools and resources for chemistry, computational chemistry, drug discovery, and related research workflows.

---

## Tools

| Tool | Description | Type | Access | Interface | Platforms | ChemIsFree Status |
|---|---|---|---|---|---|---|
| [Biopython](https://biopython.org/) | Python tools and libraries for computational molecular biology and bioinformatics, including sequence analysis, structure handling, databases, and biological data processing. | library | Free | Python | Linux / Macos / Windows | Curated Resource |
| [CataList](https://github.com/DionysisKampasis/CataList) | Desktop chemical inventory management software for laboratories and researchers, providing chemical structure generation, molecular property calculation, chemical classification, and exact, substructure, and similarity searching. | software | Free | Gui | Desktop | **ChemIsFree Project** |
| [Chemistry Development Kit](https://cdk.github.io/) | Open-source modular Java library for cheminformatics and bioinformatics, supporting chemical structures, fingerprints, descriptors, searching, and file formats. | library | Free | Java | Linux / Macos / Windows | Curated Resource |
| [Open Babel](https://openbabel.org/) | Open chemical toolbox for converting, analyzing, searching, and processing chemical data across numerous molecular file formats. | library | Free | Cli / Python / C++ | Linux / Macos / Windows | Curated Resource |
| [RDKit](https://www.rdkit.org/) | Open-source cheminformatics and machine-learning software for working with molecular structures, descriptors, fingerprints, molecular databases, and related chemical data. | library | Free | Python / C++ | Linux / Macos / Windows | Curated Resource |
