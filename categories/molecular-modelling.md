# Molecular Modelling

Tools and resources for chemistry, computational chemistry, drug discovery, and related research workflows.

|---|---|---|---|---|---|---|

| [OpenMM](https://openmm.org/) | Toolkit for molecular simulation that can be used as a stand-alone application or as a library for custom simulations. | library | Free / Open Source | Python / C++ / Cli | Linux / Macos / Windows | Curated Resource |
