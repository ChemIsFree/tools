# ChemIsFree Tools

**A curated catalogue of free and open tools for chemistry and drug discovery.**

ChemIsFree Tools is a community-curated collection of software, web applications, databases, libraries, and other resources useful for chemistry, cheminformatics, computational chemistry, and drug discovery.

The goal is simple:

> **Make useful tools easier to find.**

Instead of searching across scattered repositories, papers, websites, and forums, researchers can use ChemIsFree as a starting point for discovering tools relevant to their work.

---

## Browse the catalogue

### 🧪 Chemistry & Cheminformatics

Tools for molecular representations, descriptors, fingerprints, chemical structures, reactions, and cheminformatics.

### 🧬 Molecular Modelling

Tools for molecular mechanics, quantum chemistry, molecular dynamics, structure preparation, and molecular visualization.

### 🎯 Drug Discovery

Tools for molecular docking, virtual screening, pharmacophore modelling, QSAR, ADMET, lead optimization, and molecular design.

### 🤖 Artificial Intelligence & Machine Learning

Tools for molecular property prediction, generative chemistry, graph-based modelling, protein–ligand modelling, and other AI applications.

### 📊 Data & Analysis

Chemical databases, bioactivity resources, datasets, data-processing tools, and scientific analysis software.

### 🔬 Experimental & Laboratory

Software and resources supporting experimental chemistry and laboratory workflows.

### 🛠️ Utilities & Workflows

File conversion, workflow automation, pipeline development, format handling, and other useful utilities.

## What counts as a ChemIsFree tool?

The catalogue may include:

* Open-source software
* Free-to-use software
* Free web applications
* Open scientific databases
* Open datasets
* Python/R/Java/C++ and other scientific libraries
* Research workflows
* Useful community projects
* Other freely accessible resources relevant to chemistry and drug discovery

A project does **not** need to belong to ChemIsFree to be included.

---

## Ownership & attribution

ChemIsFree does not claim ownership of independent projects listed in this catalogue.

Projects remain the property of their respective creators and contributors and are presented with appropriate attribution and links to their original sources.

We distinguish between:

**ChemIsFree Projects**
Projects developed under the ChemIsFree organization.

**Community Projects**
Independent projects whose creators participate in or are associated with the ChemIsFree ecosystem.

**Curated Resources**
Independent external tools and resources included because they may be useful to the community.

Being listed in the catalogue does not by itself imply that a project is owned, developed, endorsed, or maintained by ChemIsFree.

## Quality and curation

ChemIsFree aims to provide useful and accurate information rather than simply collecting as many links as possible.

Catalogue entries may include information about:

* Functionality
* Supported platforms
* Interfaces
* Licensing
* Documentation
* Installation
* Maintenance status
* Scientific publications
* Original developers
* ChemIsFree project status

Information should be verified against the project's official sources where possible.
